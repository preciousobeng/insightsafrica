# Self-hosted homepage fonts

fonts.css defines only local @font-face sources; no runtime Google Fonts request. Fraunces uses weight 600 and variable optical size (9–144); use font-optical-sizing:auto in homepage typography. IBM Plex Sans supports variable weight 100–700; IBM Plex Mono is regular 400 for numeric labels with font-variant-numeric:tabular-nums.

These are official Google Fonts Latin WOFF2 assets. Source URLs, SHA256, subset and OFL licence provenance are recorded in provenance.json. All three font licences permit web embedding and redistribution; retain these licence files. IBM reserves the name Plex for modified derivatives; these official files are unmodified.
